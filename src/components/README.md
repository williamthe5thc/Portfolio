# Components Directory

## Structure

### Shared Components
- `features/`: Feature-specific components
  - CoreCompetencies
  - EnhancedComponents
- `layout/`: Layout components
  - CallToAction
  - Navigation
  - PageHeader
  - LoadingScreen
- `utils/`: Utility functions and animations

### UI Components
Base components used throughout the application:
- BaseCard
- Button
- FormElements
- ImagePlaceholder
- LoadingSpinner
- LoadingStates

### Cards
Reusable card components:
- JourneyCard
- PhilosophyCard
- ProjectCard
- StatsGrid
