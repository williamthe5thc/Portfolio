# Archived Portfolio Projects

## Purpose
These projects are kept in source but deliberately not shipped. They are excluded
from `src/content/projects.ts`, so they do not render anywhere on the site.

## Research Findings
- Hiring managers review a maximum of 3-6 projects and judge by the best piece, not the total
- Non-ID projects dilute focus and confuse hiring managers about career direction
- A curated set outperforms a catalog; "three pieces you stand behind beat eight of varying quality"
- Live, clickable work beats screenshots — hiring managers click before they read
- Articulate Storyline 360 proficiency is the baseline screen for corporate ID roles

## Important: archived means *moved*, not *copied*
An earlier pass copied files into this folder while leaving the originals in
`../`, so four projects existed twice and the shipping versions kept rendering.
`ego-depletion`, `empathy-research`, `how-to-videos`, and `yahtzee-game` were the
affected ones — the richer `../` versions won and the stubs here were replaced.

If you archive something in future, **move** the file and delete its import from
`src/content/projects.ts`. A file in this folder that is still imported is still live.

Personal creative work does not demonstrate instructional design thinking.

### Academic Research Projects

Strong research foundation, but too far from applied ID practice to lead with.
Still cited on the Academic resume as credentials — without portfolio links,
since these pages no longer exist.

`gamification-stem-education.ts`, `stakeholder-digital-engagement.ts`,
