## CRITICAL TECHNICAL SETUP (Read This First!)

### Tech Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Framer Motion
- **Deployment**: GitHub Pages via gh-pages package
- **Build Tool**: Vite (NOT Create React App)

### Essential Development Workflow
```bash
# 1. ALWAYS start with dependencies installation
npm install

# 2. Local development
npm run dev  # Starts on localhost:3000

# 3. Deploy to staging for testing
git add .
git commit -m "Your changes"
git push origin branch-name
npm run deploy  # Deploys to Portfolio-Staging

# 4. Deploy to production
npm run deploy:production  # Deploys to main Portfolio
```

### Multi-Environment Configuration
- **Development**: `npm run dev` - Base path `/`
- **Staging**: `npm run deploy` - Base path `/Portfolio-Staging/`
- **Production**: `npm run deploy:production` - Base path `/Portfolio/`

### Troubleshooting Quick Fixes
1. **"Command not found" errors**: Run `npm install` first
2. **Import errors**: Check exact file paths, use @ aliases
3. **Build failures**: Check TypeScript types in src/types/content.ts
4. **GitHub Pages 404s**: Deploy script pushes to gh-pages branch automatically
5. **Missing CSS**: Ensure src/styles/index.css exists with Tailwind directives

### File Requirements (Create if Missing)
- `src/styles/index.css` - Tailwind CSS directives
- `src/pages/NotFoundPage.tsx` - 404 error page
- `src/content/projects.ts` - Exports projects array
