NACVA Course Automation Demo

Simplified browser versions of scripts I wrote at NACVA, running on sample data

About this demo

At NACVA, adding a course to the website meant typing its details in by hand. I wrote Python scripts that took over that data entry, checked the data for errors, and converted Word and Excel files into formats the site could use.

The originals ran on NACVA's own files and systems, so they can't be shared. These two tools are simplified recreations of the idea that run in your browser. Nothing you type or upload leaves this page.

What the original scripts did

Replaced manual entry

Course details that staff used to key in by hand went in through a script instead.

Checked the data

Each record was checked for missing or malformed values before it was entered.

Converted files

Word and Excel source files were converted into the formats the website needed.
